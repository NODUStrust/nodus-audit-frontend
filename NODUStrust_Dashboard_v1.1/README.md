# NODUStrust Dashboard v1.1 (scaffold)

Minimal scaffold generated by Monday (GPT-5) to reproduce the NODUStrust Dashboard structure.

## Contents
- frontend/ - Vite + React + Tailwind placeholder app
- backend/  - Express API with /api/audit-log mock
- docs/     - sample preflight checklist JSON and sample export script

## Next steps (manual)
1. Install deps in each folder: `npm install` inside frontend and backend.
2. Set environment vars (see .env.example).
3. Run backend: `node index.js` (backend folder).
4. Run frontend: `npm run dev` (frontend folder).
